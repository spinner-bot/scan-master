# scan-master

scan-master 是一个面向 Windows 系统盘（C:）的本地扫描与清理工作区：以只读方式枚举分区、按阈值逐层拆解存储结构，输出分级清理建议，并记录清理执行过程，在不动系统关键文件的前提下回收可用空间。

## 项目做什么

- **只读扫描**：扫描区绝不写入，所有脚本、原始数据与日志都存放在本地工作站。
- **阈值剪枝**：从分区根目录按广度优先逐层展开，初始阈值 256 MB，未展开部分超过 5% 容量则阈值减半，直至结构足够清晰。
- **分级清理**：按 `3 → -2` 六级标准区分“可立即删除”到“绝对不能清理”，重点关注缓存、更新包、崩溃转储等可重建内容。
- **全过程留痕**：扫描阈值、权限受限目录、完整结果树、清理建议与逐项执行日志均落盘保存。

## 目录结构

```
scan-master/
├─ docs/       扫描流程与版本管理规范
├─ temp/       本地工作站：每次扫描/清理的脚本、原始数据与日志（不入库）
├─ backup/     清理前移出的个人文件备份（不入库）
└─ report/     按编号生成的报告与扫描结果（不入库）
```

`temp/`、`backup/`、`report/` 只提交各自的 `README.md`，实际内容因包含本机磁盘数据与个人文件而不纳入版本库，具体说明见各目录 README。

## 工作流程

1. 在 `temp/` 下创建以时间戳命名的专属工作站。
2. 按 `docs/分区扫描.txt` 对目标分区执行只读扫描，动态调整阈值。
3. 分析扫描记录，在 `report/<编号>/` 下撰写分区存储结构报告与清理建议分级报告。
4. 按授权级别执行清理，移出的个人数据存入 `backup/`，并记录逐项执行日志。
5. 按 `docs/版本管理规范.txt` 逐文件提交。

报告目录编号为 `YMDD-NN`（年份末位 + 月份字母 + 日期 + 当日序号），例如 2026 年 10 月 22 日的第 1 份报告为 `6A22-01`。

## 快速开始

```bash
git clone git@github.com:spinner-bot/scan-master.git
cd scan-master
```

运行环境为 Windows，扫描与清理依赖 PowerShell，数据分析使用 Python 3。仓库提供规范与目录骨架；具体扫描/清理脚本随工作站保存在本地 `temp/` 中，不随仓库分发。

## 数据与隐私

- 扫描结果、报告、备份与工作站数据均只保留在本机，`.gitignore` 对三个目录只放行 `README.md`。
- 克隆仓库后可得到完整的目录结构与规范，但不会包含他人的磁盘扫描数据或备份文件。
- 历史提交中可能仍包含早期入库的报告数据，当前版本已不再跟踪。

## 示例

6A22-01 首次执行中将一块 100 GB、使用率 99.77%（仅剩 236.1 MB）的 C 盘清理出约 13.0 GB 可用空间，包括 PyCharm 崩溃堆转储、pip/npm 缓存、WPS 插件池、飞书与 OneDrive 旧版本文件等。完整报告保留在本地 `report/6A22-01/`。
